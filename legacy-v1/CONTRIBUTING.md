# Как участвовать

1. Форкните репозиторий и создайте ветку: `git checkout -b feature/short-name`.
2. Установите зависимости: `npm ci`.
3. Запустите разработку: `npm run dev`.
4. Перед коммитом прогоните `npm run lint && npm test`.
5. Опишите изменения в PR: что сделано, зачем, как проверить.

## Правила кода

- Только ES‑модули, без CommonJS в `src/`.
- Серверные обработчики живут в `src/server/routes/` и не пишут в `res` напрямую —
  возвращают данные через `send` / `fail` из `http.js`.
- Клиентские экраны — в `src/client/features`, общие элементы интерфейса — в `src/client/ui`.
- Новые строки интерфейса — на русском, без англицизмов там, где есть привычный термин.
- Форматирование — Prettier (`npm run format`), правила — ESLint (`npm run lint`).

## Тесты

Новое поведение API сопровождайте тестом в `tests/api.test.js`. Тесты поднимают
сервер на случайном порту и используют временный `DATA_DIR`, поэтому не трогают
рабочие данные.
